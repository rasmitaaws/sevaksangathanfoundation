# Sevak Sangathan Foundation

Official static website for Sevak Sangathan Foundation.

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Free deployment

This site is designed for GitHub Pages. Enable Pages in the repository settings and select the main branch with the root folder as the source.
